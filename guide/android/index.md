mica-mqtt-client 与 mica-mqtt-server 均可用于 Android 原生项目（需 2.4.2 或以上版本）。

* [mica-mqtt client Android 原生客户端使用文档](client.md) —— Gradle 依赖、INDEX.LIST 排除、客户端初始化配置与全局订阅，附运行效果截图。
* [mica-mqtt server Android 原生服务端使用文档](server.md) —— Gradle 依赖、服务端启动配置、混淆规则，以及 WebSocket、HTTP API 所需依赖说明。

> 需要普通 Java 应用的接入方式，请看 [mica-mqtt client 客户端使用文档（Java）](../java/client.md)。
